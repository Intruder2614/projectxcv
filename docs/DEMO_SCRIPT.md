# 4-minute CEO demo script

**Positioning:** Code Studio is a teaching intelligence and collaboration workspace. Code is the evidence; coordinated teaching action is the differentiator.

1. **Overview (40 seconds):** show average concept mastery, assignment completion and the priority learner queue. Explain that the numbers shown in the pilot are fictional.
2. **Learner intelligence (45 seconds):** open a learner, review concept scores, completion and recent mastery movement. Explain that support flags are transparent prompts for teacher review, not automated diagnoses.
3. **Teacher collaboration (60 seconds):** create a follow-up with an owner, priority, due date and next step. Add a comment and mark it resolved. Explain the intended future benefit: make teacher handoffs explicit rather than scattered across messages.
4. **Assignments (35 seconds):** create a task with a learning objective and show submission/completion summaries.
5. **Project continuity (45 seconds):** open the coding workspace, save a file, create a named Git commit, then show version history and restore-as-new-commit behaviour.
6. **Close (15 seconds):** propose a measured teacher pilot. Success should be evaluated on follow-up quality/resolution, teacher usefulness, assignment progress and concept mastery before making impact claims.

## Questions to pre-empt

- **Is it live Codingal data?** No. The demo data is fictional; the app is not connected to Codingal production.
- **Can teachers collaborate across machines today?** Not yet. The notes/comments persist in a local database; multi-user identity and shared deployment are production work.
- **Is the code runner production-secure?** The optional Docker runner is a local pilot control. A public multi-tenant runner needs a separate security review and hardened isolation.
- **What is the differentiation?** Concept-to-action insight and auditable teacher follow-through, with coding projects and Git history available in one workflow.
